# Interactive Developer Portfolio

A modern, highly interactive, and responsive personal portfolio website built with React, Vite, and Tailwind CSS v4. Designed to showcase projects, skills, and professional journey with premium UI/UX features.

## ✨ Features

- 🌓 **Dark & Light Mode**: Seamless theme switching with system preference detection.
- 🪄 **Premium Animations**: Smooth scroll reveals, page transitions, and interactive elements powered by Framer Motion.
- 🔦 **Interactive Spotlight Effect**: High-end SaaS-like cursor tracking glow effects on Project and Skill cards.
- 📊 **Scroll Progress Indicator**: Dynamic top-bar progress indicator that fills as you scroll.
- 📱 **Fully Responsive**: Mobile-first design that looks great on any screen size.
- 📄 **Interactive Resume Modal**: Built-in resume viewer without leaving the page.
- 🎨 **Modern Tech Stack**: Fast development and optimized production build using Vite and Tailwind CSS.

## 🛠️ Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS v4
- **Animations**: Motion (Framer Motion)
- **Icons**: Lucide React
